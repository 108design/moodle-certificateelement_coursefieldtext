# Certificate Multitool guides

These guides cover the complete Certificate Multitool pair. Install [Custom Field](https://github.com/108design/moodle-customfield_multiline) to maintain course values and [Cert. Element](https://github.com/108design/moodle-certificateelement_coursefieldtext) to place them on certificate templates.

| Audience | Guide | PDF |
| --- | --- | --- |
| Course editors | [Course editor guide](COURSE_EDITOR_GUIDE.md) | [Download PDF](COURSE_EDITOR_GUIDE.pdf) |
| Administrators and certificate designers | [Administrator guide](ADMINISTRATOR_GUIDE.md) | [Download PDF](ADMINISTRATOR_GUIDE.pdf) |

The course editor guide explains saved course values, Plain text and Limited HTML, alignment choices and the course preview. The administrator guide covers both plugin installations, Certificate manager and Course certificate prerequisites, template setup, hidden fields, text areas and issued certificates.

Both guides are available as Markdown and PDF in each repository. They use neutral examples without screenshots or customer branding.
